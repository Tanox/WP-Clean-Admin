## 2. 录制前准备

### 2.1 环境清单

| 项目 | 要求 | 检查方法 |
|------|------|----------|
| WordPress | ≥ 5.0 | 后台「站点健康」或 `wp_version()` |
| PHP | ≥ 7.4 | 主机面板或 `php -v` |
| 插件版本 | 1.9.18 | 插件列表「版本」列 |
| 演示账号 | 管理员（具备 `manage_options`） | 后台右上角用户名 |
| 浏览器 | Chrome / Edge 最新版，缩放 100% | — |
| 屏幕分辨率 | 1920×1080（录制 1920×1080，文字区不超过 1440px 宽） | — |
| 录屏帧率 | 30fps 足够，关键点击处可放大 | — |

### 2.2 内容准备

1. **恢复干净的测试数据**：准备一个含 3–5 篇示例文章、1 个自定义页面、2–3 个仪表盘小部件的站点，确保「清理前后对比」有画面素材。
2. **提前关闭无关通知**：关闭 WordPress 更新提示与其他插件的弹窗，避免录制中弹出干扰画面。
3. **准备对比素材**：录制「清理前」与「清理后」的后台首页截图各一张，用于片头/片尾对比镜头。
4. **清理浏览器状态**：录制前关闭开发者工具浮窗避免遮挡；需要展示 Network 面板的片段单独录制。

## 9. 字幕与配音规范

| 项目 | 规范 |
|------|------|
| 字幕字体 | 无衬线（如思源黑体 / Noto Sans SC），字号不低于画面高度的 4% |
| 字幕位置 | 底部安全区内，距底边 ≥ 8% 高度；每屏 ≤ 2 行、每行 ≤ 20 个汉字 |
| 字幕内容 | 与旁白逐字稿一致；专业名词保留原文（REST、nonce、WP-Cron、JSON、PHP） |
| 术语统一 | 使用「设置页」「选项卡」「菜单定制器」「小部件」「缓存后端」等文档统一术语，不使用「面板」「标签页」等近义混用 |
| 配音 | 中文男声或女声均可，语速约 220–260 字/分钟，句末留 0.3 秒停顿 |
| 音效 | 仅在点击、提示出现时加轻量提示音，音量不超过 -18dBFS |
| 背景音乐 | 轻量 lo-fi / 无衬线铺底，音量 -24dBFS 以下，人声段落自动压低 |
| 无障碍 | 每集提供字幕文件（`.srt`）；关键操作额外加文字卡，不依赖颜色区分 |
