## 一、严重事件：prototype 目录数据丢失（已恢复）

### 现象
会话中段（重构任务中断）导致 `assets/prototype/` 下 16 个文件从工作区被删除，仅剩

`app.js`，但二者缺失 → **原型当时完全无法运行**。

### 原因
`git status` 显示 16 个 `D`（删除未暂存），但 `git ls-files` 确认 HEAD 中完整跟踪这些文件。
即删除发生在工作区，未提交，HEAD 为可用基线。推断为前一轮工具调用中断导致写入未落盘
且后续删除指令未回滚。

### 处置（已执行）
`git -C e:\Github\WPCleanAdmin checkout HEAD -- wpcleanadmin/assets/prototype`
→ 16 个文件已全部从 HEAD 还原，原型恢复可运行。新建 `ui/index.html` 保留。

> 注意：还原的是 HEAD 版本（未含本轮"继续修复"的 P0-2/P1-2 改动，因那些改动从未持久化）。
> 即 app.js 仍是 P1-2 XSS 旧版（innerHTML 拼接），dashboard.html 仍是旧入口。

## 九、第四次审查：原型结构冗余与引用失效（2026-08-08）

用户再次"审查项目"。重点核查根 `prototype/`（已从插件目录移出）。发现结构冗余 + 路径失效。

### P0 结构冗余（prototype 内部）
1. **同名类冲突**：`php/class-wpca-module-dashboard.php`（根级，旧示例模板）与
   `php/modules/class-wpca-module-dashboard.php`（高保真版）同 namespace `WPCleanAdmin\Modules\Admin`，
   若同时 autoload 会 fatal。根级版本是过时教程模板。
2. **双 UI 入口**：`ui/dashboard.html`（旧）与 `ui/index.html`（新）并存 → 应删 dashboard.html。
3. **孤立样式**：`ui/settings-page.css` 引用方 `settings-page.html` 已删 → 孤立文件，应删。

### P0-2 仍未修（HEAD 旧版）
`php/class-wpca-module-dashboard.php:34` 仍注册 `wpca_dashboard_save`（与 Settings 模块
`wpca_settings_save` 冲突）。高保真版 `php/modules/...dashboard.php` 已无此 action（正确）。
说明根级模板是未修复的旧版。

### P1 路径/引用失效（原型移出插件目录后）
- `ui/index.html:4` 注释引用 `assets/prototype/DESIGN.md` → 实际应为 `/prototype/DESIGN.md`（且 DESIGN.md 未创建）。
- `php/class-wpca-module-dashboard.php:67` 与 `php/modules/...dashboard.php:41`
  `include WPCA_PLUGIN_DIR . 'assets/prototype/ui/...'` → 原型已不在插件 assets 下，路径无效。
- `README.md:4/21/29/51` 引用 `assets/docs/设计规范_20260808.md`、`ui/dashboard.html` → 应为 `docs/设计规范_20260808.md`、`ui/index.html`。
- `wpca-components.css:2`、`app.js:4`、`settings.php:5` 引用 `设计规范_20260808.md` 无前缀，实际位于 `docs/`。

### 设计规范现状
`docs/设计规范_20260808.md`（7.85KB）已存在，但原型内引用路径未对齐；且此前要求的
`/prototype/DESIGN.md` 未创建（index.html 注释指向它）。

### 结论（待执行，需用户批准删除）
1. 删 `php/class-wpca-module-dashboard.php`（过时模板，含 wpca_dashboard_save 冲突）。
2. 删 `ui/dashboard.html`、`ui/settings-page.css`（保留 index.html + wpca-components.css）。
3. 修正 `php/modules/...dashboard.php:41` include 路径为 `prototype/ui/index.html`（或原型脱离插件目录后的实际路径）。
4. 全量修正原型内文档引用路径（`assets/prototype/*` → `/prototype/*`，`assets/docs/*` → `/docs/*`）。
5. （可选）创建 `/prototype/DESIGN.md` 或统一指向 `/docs/设计规范_20260808.md`。

> 以上为审查发现，删除/移动动作待用户明确批准后执行（遵循"删除需明确批准"）。
