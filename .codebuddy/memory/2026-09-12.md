## 修复 CI 阻塞：非法 WP 函数 stub 声明（1.8.8 续）

- CI 第二个错误：`performance-ajax.php` 第 19 行 `PHP Parse error: unexpected fully qualified name "\wp_send_json_error", expecting "("`。根因：`function \wp_send_json_error() {}` 这类 "IDE compatibility" stub 声明语法非法（`function` 关键字后不能带命名空间前缀）。
- 全项目 `function\s+\\` 搜索：仅 `wp-clean-admin.php`（主文件，无 namespace，~18 个 WP 函数 stub）与 `performance-ajax.php`（6 个）含此非法声明；其余 ajax 文件只有合法调用 `\wp_send_json_error()`。
- 修复：整块删除这两处 stub（用 node 脚本按注释锚点删除，避开反斜杠转义），保留主文件第 25-26 行对 `\plugin_dir_path()`/`\plugin_dir_url()` 的合法调用（运行时 WP 提供，非 WP 环境走 `function_exists` fallback）。
- 教训：WP 插件**不应**为 WP 核心函数写空 `function` stub（语法非法 + 运行时与核心冲突）；IDE 类型提示应改用 `@global` / `phpcs` WP 规则集，而非声明空函数。此 stub 是之前"统一作者署名 + IDE 兼容"时引入的冗余死代码。
