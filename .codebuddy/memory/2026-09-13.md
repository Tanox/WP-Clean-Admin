# 2026-09-13

## CI 第二轮修复（1.8.9）：php-lint / phpunit 阻塞项

CI 在 composer 修复（1.8.8 已提交推送）后暴露真实缺陷，已全部修复：

- `performance-ajax.php`：WP 函数调用处双反斜杠 `\\wp_send_json_error` / `\\__` 非法语法（被先前已删的 IDE stub 声明掩盖，stub 删除后才暴露）。用脚本把全文 `\\`→`\`（14 处）。
- 删除 `tests/PrototypeTest.php`：其 `setUp()` 仍 require 已被清理的 `prototype/php/` 目录，PHPUnit 致命错误。
- 重写 `tests/bootstrap.php`：提前 `define('ABSPATH')` 阻止 autoloader 加载空白 `wpca-wordpress-stubs.php`，提供最小 WP 函数 polyfill（`sanitize_text_field` 正确实现：去 script/style + strip_tags + trim），并显式 `require wpca-core-functions.php`（定义 wpca_get_settings/version/text_domain 等）。使单元测试在无 WP 环境下可运行。
- `phpcs.xml.dist` 增加 `installed_paths`（vendor/wp-coding-standards/wpcs 等），修复 "Referenced sniff does not exist"（WordPress 标准此前未注册）。phpcs 步骤为 continue-on-error（非阻塞）。
- 版本 bump 1.8.8 → 1.8.9（主文件 `Version:`/`WPCA_VERSION`、README、CHANGELOG）。

### 架构认知（长期）
- `includes/autoload.php`：当 `!defined('ABSPATH')` 时 `require wpca-wordpress-stubs.php`（空实现 IDE stub）并 define ABSPATH。bootstrap 提前 define ABSPATH 即可跳过加载 stub。
- `includes/wpca-core-functions.php` 顶部 `if (!defined('ABSPATH')) exit;`：bootstrap define ABSPATH 后才能安全 require。
